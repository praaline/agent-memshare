# ADR-0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-05

## Context

Decisions about `memshare` need to be understandable later, by people and by coding agents.

## Decision

Significant decisions are recorded as ADRs in `docs/adr/`, numbered, one per file: context, decision,
consequences. An ADR describes the current decision; when a decision changes, its ADR is updated or
superseded by a new one that says so.

## Consequences

- The ADRs and [the design overview](../design.md) are the reference for how and why the tool works.
