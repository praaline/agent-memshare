# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately: on GitHub, open the repository's **Security** tab and choose
**Report a vulnerability**. Don't open a public issue. You'll get an answer within a week.

## Supported versions

Fixes go into the latest release.

## How memshare is secured

See [docs/security.md](docs/security.md): the trust model, deploy keys and pinned host keys, the
secret check, and how releases are built and verified.
